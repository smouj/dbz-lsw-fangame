# Code of Conduct

## Our standard

Everyone participating in this project is expected to help make collaboration respectful, constructive and welcoming.

Examples of behavior that supports this standard include:

- Being considerate and direct without personal attacks.
- Welcoming different levels of experience and viewpoints.
- Giving and receiving feedback with respect.
- Focusing discussion on the work and its evidence.

Unacceptable behavior includes harassment, discrimination, threats, deliberate intimidation, sexualized attention without consent, and publishing another person's private information.

## Project spaces

This policy applies to issues, pull requests, code reviews, discussions and other project spaces.

## Enforcement

Report a concern privately to the repository owner through GitHub. Reports will be reviewed and handled with discretion. The project owner may edit or remove content and restrict participation when needed to protect the community.
